🔮 Zodiac Sign Teller with Voice 🎙️
This is a beginner-friendly Python program that calculates your Zodiac sign from your birth date — and speaks it out loud using the pyttsx3 text-to-speech engine. A fun blend of astrology and automation!

✨ Features:
Interactive CLI: Takes your name, birth month, and date

Detects your Zodiac sign with emoji

Uses text-to-speech to announce your sign

Built with clean logic and user input handling
